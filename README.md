# MeteoricKeyboards

Simple storefront website for custom-built keyboards.

## Run locally

Open `/home/runner/work/MeteoricKeyboards/MeteoricKeyboards/index.html` in a browser, or serve the folder:

```bash
cd /home/runner/work/MeteoricKeyboards/MeteoricKeyboards
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
